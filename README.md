# 寶可夢 GO 去留指南（Keep or Transfer）

把《Pokémon GO》裡 1717 個實裝型態（區域形態、超級進化、暗影、極巨化⋯）一次列齊，
告訴你**哪些值得留下、哪些可以直接傳送**，還能輸入自己那隻的 IV 算對戰排名。

## 🌐 直接線上使用

**https://xiangwang2000.github.io/pokemon-go-keep-or-release/**

不用安裝任何東西，手機或電腦的瀏覽器打開就能查。想留在本機跑也可以：

```powershell
python -m http.server 8600 --directory site
# 然後開 http://localhost:8600/
```

## 怎麼用

1. **找哪隻**：搜尋框輸入中文／英文名或編號；也可以用屬性、評級、類別（傳說／暗影／極巨化⋯）、世代下拉篩選。
2. **看評級**：每張卡片右上是四級判定——必留／建議保留／看情況／可傳送；點卡片看完整理由（PvP 排名、限制盃榜、PvE 估算、極巨戰估算、推薦帶法）。暗影個體另外附**淨化建議**（要不要直接淨化、幾級條件可淨百）。卡片底下的小字是**各衡量尺度並列**（CP · PvP 名次 · PvE 百分位 · Max 百分位），存在才顯示，不是「適合哪邊」的意思。
3. **算 IV**：詳細頁最下方有計算機，填入那隻的攻／防／血，會回報各聯賽的 IV 排名與最佳等級；暗影個體會連帶顯示**淨化後 IV**（淨百就會直接喊出來）。
4. **標記收藏**：詳情頁的「標記這隻」按鈕可在保留／可送／已送之間循環，方便清理前清點——記錄存在自己的瀏覽器裡。

## 評級怎麼判

| 條件 | 評級 |
|--------------------------|----------------|
| 幻獸 / 超極巨化 / 超級進化 / 各聯賽前 50 名 / PvE 估算前 3% | 必留 |
| 已暗影且排名前 200 / 傳說 / 異獸 / PvP 前 150 / PvE 前 10% / 現行限制盃前 50 名 / 極巨戰攻手估算前 10% | 建議保留 |
| 區域限定 / 未完全進化 / PvP 前 350 | 看情況 |
| 其餘（附圖鑑例外說明） | 可傳送 |

Max Battle 只有極巨化個體能出戰，所以可極巨化型態另有一套攻手估算（極巨攻擊 DPS），不跟普通 PvE 混著比——
龍頭地鼠普通 PvP／PvE 都不突出，極巨戰卻是社群公認的頂尖攻手。完整規則見[開發說明](docs/DEVELOPMENT.md)。

## 資料與免責

- 數值來自開源社群資料：[PvPoke](https://pvpoke.com)（型態、排行榜）、[PokeMiners GameMaster](https://github.com/PokeMiners/game_masters)（PvE 數值、進化方向）、[pokemondb](https://pokemondb.net/go/dynamax-attackers)（極巨化清單）、[WatWowMap](https://github.com/WatWowMap)（型態圖示）等，完整致謝見[開發說明](docs/DEVELOPMENT.md)。
- PvE 強度為估算值、盃賽 meta 隨季輪替（榜單標明撈取日期）；極巨戰估算只假設極巨攻擊威力 250 的同尺度近似（超極巨專屬招式威力略異），取的是**相對排名**不是精算傷害；判斷以攻略建議為性質，非官方資料。

## 本 repo 的結構

```
site/   網站本體（GitHub Pages 上線的是這個資料夾）
data/   建置用原始資料（PvPoke、PokeMiners、uicons 等來源快取）
tools/  資料抓取與建置腳本；tools/archive/ 是研究階段的一次性探查工具
docs/   開發者文件（資料更新流程、判定規則細節）
```

## 幫它活著

資料來源會隨 GO 改版而舊（例如盃賽榜、Ja 新寶可夢）。如果你發現哪隻的評級怪怪的、
或最近實裝到 GO 的新寶可夢還沒出現在站上，歡迎開 issue 回報。

想自己跑建置、研究判定規則、或者修正資料？開發流程都整理在[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)——
幾個 node 指令就會跑完抓取、建置、稽核三步。
